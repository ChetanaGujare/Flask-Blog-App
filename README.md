# 📝 Flask Blog App

A simple, modern blog application built using **Flask** and **Jinja2** for Server-Side Rendering (SSR).

## ✨ Features
- **View Posts:** Displays a list of all blog posts on the home page.
- **Post Details:** Click on any post to read the full content.
- **Comments System:** View existing comments on a post and submit new comments via a form.
- **Template Inheritance:** Uses a `base.html` layout for consistent header and footer across pages.
- **Dynamic Rendering:** Uses Jinja2 loops (`{% for %}`) and conditions (`{% if %}`) to render data from the Flask backend directly into HTML.

## 🛠️ Tech Stack
- **Backend:** Python 3, Flask
- **Frontend:** HTML5, CSS3 (Custom Styling)
- **Templating Engine:** Jinja2
- **Data Storage:** In-memory Python dictionaries (for demonstration purposes)
